## Что уже есть

Полная спецификация с сигнатурами кода, дизайн-решениями и перечнем
тест-кейсов по модулям уже записана в
**`docs/TECHNICAL_PLAN.md` §«Этап 8 — Sitemap: из robots.txt (POST_MVP)»**
(коммит `80bc68b`). Она включает:

- контракт `RobotsCache.sitemaps()` (готовый сниппет кода);
- контракт `extract_sitemap_urls()` в `fetcher.py` (сигнатура + докстринг,
  возвращает `(page_urls, nested_sitemap_urls)`);
- интеграцию в `Crawler._process`/`_discover_sitemaps` (готовый сниппет);
- решение по глубине sitemap-URL (`depth=0`) с обоснованием;
- решение по `<sitemapindex>` (один уровень, без рекурсии — POST_MVP);
- решение по gzip-sitemap (не поддерживается — POST_MVP);
- новый счётчик `CrawlStats.sitemap_urls`;
- список имён тест-кейсов для `tests/test_robots.py`, `tests/test_fetcher.py`,
  `tests/test_cli.py` (без кода тестов, только что каждый должен проверять);
- границы («что НЕ входит») и критерий «готово когда».
